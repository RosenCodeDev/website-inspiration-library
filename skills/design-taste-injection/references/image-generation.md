# Image Generation

Generate only after the user approves the category, reference set, variant, build path, and code-built H0 hero.

## Provider choice

Ask once:

- **Codex image generation:** default; no additional account.
- **Higgsfield:** optional; use only when its skill and authenticated account are available.

If Higgsfield is absent, continue with Codex. Never require its installation.

## Prompt construction

Start from the selected card recipe and adapt it to the real project. Include:

- Asset role and subject.
- Output geometry and intended crop.
- Subject placement and protected HTML text region.
- Lighting or explicit flat/no-lighting treatment.
- Palette boundary.
- Texture and material treatment.
- Exclusions: source branding, logos, people, product identity, generated copy, and interface text.

Use reference images only when allowed and useful. Treat generated visuals as new project assets, never as evidence about the source reference.

## Output

Create four meaningfully different images, not seed variations. Name them by hero lineage `H1…H4`, preserve H0, place all five in the workbench, and keep the user at the hero checkpoint until one is approved or H0 is retained.
